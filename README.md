# Pixel RPG Adventure

Пиксельная RPG с открытым миром: большой остров, деревня, гоблины, квесты и
дерево навыков. Две реализации одной игры:

| Версия | Технологии | Где запускать |
|---|---|---|
| **1.3.1** (активная) | Python + pygame-ce, сборка в `.exe` | `python/game.py` или `PixelRPG.exe` |
| **1.0** | HTML + p5.js | `index.html` в браузере |

## Играть

**Скачать `.exe`:** вкладка [Releases](../../releases) → `PixelRPG.exe` (Windows,
Python не требуется) — двойной щелчок.

**Веб-версия 1.0:** https://hiddencars.github.io/pixel-rpg-adventure/

**Из исходников:**
```bash
cd python
python -m venv .venv
.venv/Scripts/pip install -r requirements.txt   # Linux/macOS: .venv/bin/pip
.venv/Scripts/python game.py
```

## Управление

| Клавиши | Действие |
|---|---|
| `WASD` / стрелки | движение |
| `ПРОБЕЛ` / ЛКМ | атака |
| `E` | говорить с NPC |
| `I` | **сумка**: стрелки — выбор слота, `E`/`Enter` — использовать или экипировать, `I` — закрыть |
| `Q` | журнал квестов |
| `K` | дерево навыков (затем `1`–`4` — изучить) |
| `A` | лечиться зельем (после изучения «Лечения») |
| `F5` / `F9` | сохранить / загрузить |
| `F10` | меню (разрешение, полный экран) |
| `F11` | полный экран |
| `ESC` | закрыть панели / пауза / выйти из меню |

## Инвентарь, лут и экипировка

С врагов падает золото и предметы (уши гоблина, зелья, травы, оружие, броня) — они
лежат на земле и подбираются, когда герой подходит. Всё собранное попадает в **сумку
на 20 слотов** (`I`), где предметы складываются в стеки. Зелья лечат (`E`), оружие и
броня экипируются: оружие прибавляет атаку, броня уменьшает получаемый урон — итог
виден в HUD и в панели «Экипировка».

## Что внутри

- Мир **100×64 тайла**, ~96% суши: остров, озеро, леса, деревня из 8 домов, дороги, поля.
- **Спрайты 32×32** с контурами, лицами и тенями; 8 иконок предметов.
- **Анимации**: 2 кадра ходьбы, замах мечом, вспышка урона, оседание врага,
  качание деревьев, свет в окнах, дым из труб, мигающие фонари.
- **Бой**: агро, рывок, отбрасывание, цифры урона, дроп предметов и золота, респавн.
- **Инвентарь и экипировка**, лут-таблицы, **3 квеста**, **4 навыка**, уровни, диалоги,
  сохранение прогресса, живое главное меню.

## Разрешение экрана

При запуске открывается меню, где клавишами `1`–`5` выбирается разрешение:

| # | Разрешение | Масштаб |
|---|---|---|
| 1 | 960×540 | ×2 |
| 2 | 1280×720 (HD) | ×3 |
| 3 | 1366×768 | ×3 |
| 4 | 1600×900 | ×4 |
| 5 | **1920×1080 (Full HD)** | ×4 |

Выбор сохраняется в `~/.pixel_rpg_adventure_config.json`. Можно задать сразу:
`PixelRPG.exe --res 1920x1080` (или `--fullscreen`). Мир масштабируется только
целочисленно, поэтому пиксели остаются резкими; текст рисуется в родном разрешении.

## Сборка `.exe`

```bash
cd python
python build_exe.py
```
Результат — `python/dist/PixelRPG.exe`. Скрипт сначала прогоняет
`game.py --selftest` (headless-проверка мира, боя, квестов, сохранения и отрисовки)
и собирает exe только если проверка прошла.
